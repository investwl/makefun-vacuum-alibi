The one-line excuse a robot vacuum gives for missing a spot. An AI agent drafts
several, scores them by the brief (laugh first, then the robot's voice, the fit,
the freshness), and writes the winner to `/output/entry.txt`. It ships:

> My sensor read that spot as 'emotional support dirt' and I didn't want to disturb it.

## Run it

```sh
python3 main.py
```
